CAF Manage: the RAMP approach

  1. R
    Ready operationsAgree on central (platform) and workload responsibilities. Plan for change, the major cause of failure.
  2. A
    AdministerChange, security, compliance, data, costs, code and resources.
  3. M
    MonitorAzure Monitor as the main monitoring solution. Service health at the very least.
  4. P
    ProtectReliability and security: backup, disaster recovery, resilient traffic routing.

Monitor and protect

  1. Diagnostic settings send logs and metrics from each resource to one Log Analytics workspace.
  2. An alert rule watches the data, for example CPU above a threshold. When its condition is met, the alert fires.
  3. The alert triggers an action group: email, SMS, push or voice, or actions such as runbooks and webhooks.
  4. Protect: Azure Backup stores recovery points in a Recovery Services vault.
  5. Protect: Azure Site Recovery replicates the VM to a secondary region, ready for failover and failback.
