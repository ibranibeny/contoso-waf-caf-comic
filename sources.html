Every technical fact in the comic comes from Microsoft Learn. All 98 pages below were read on 15 November 2026; the date after each title is the page's own "last updated" date where it shows one. Learn changes often, so check the page before you present.

Naming notes (checked 15 November 2026)

  • "Application landing zones" are now called workload landing zones (Cloud Adoption Framework, What's new, October 2026).
  • The Zero Trust overview now calls the third principle assume compromise (previously "assume breach"); the WAF security principles page still says "assume breach".
  • Learn's Cache-Aside pattern suggests Azure Managed Redis. Azure Cache for Redis Basic, Standard and Premium retire on 30 September 2028, Enterprise tiers on 31 March 2027.
  • Azure Front Door (classic) retires on 31 March 2027. The comic uses Front Door Standard/Premium behavior.
  • CAF "Organize" and "Innovate" are no longer methodologies, and several CAF assessments are deprecated, so the comic doesn't use them.
