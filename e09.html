WAF · how it's organized

What's inside WAF?

  • Each pillar has design principles, a design review checklist, tradeoffs, design patterns and a maturity model.
  • Service guides help you choose and configure individual Azure services (App Service, Application Gateway, SQL Database...).
  • Workload guidance covers special workloads: AI, SaaS, mission-critical, HPC, sustainability, Microsoft Fabric.
  • Review tools: the Azure Well-Architected Review (free) and Azure Advisor.
Learn: WAF "often references Azure landing zones, but it isn't dependent on a specific platform implementation".
Sources on Microsoft Learn: What is the Azure Well-Architected Framework? (updated 2026-03-31) · Azure Well-Architected Framework · Azure Well-Architected Framework workloads (updated 2025-08-12)

The Well-Architected review loop

  1. The team takes the Azure Well-Architected Review: free, about 60 questions across the five pillars.
  2. It can pull in Azure Advisor recommendations for the workload's resources.
  3. Export the recommendations to CSV and add them to the workload backlog.
  4. Fix, deploy, repeat.
  5. Advisor score rises. Each category score represents one pillar, refreshed at least once a day.
  6. Use the assessment's milestones to re-run the review and track progress over time.
Sources on Microsoft Learn: Azure Well-Architected Review · Complete an Azure Well-Architected Review assessment (updated 2026-03-16) · Advisor score (updated 2026-05-07) · Introduction to Azure Advisor (updated 2026-05-18)
